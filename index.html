          Unseen hybrid-versus-semantic search question · Q-DEMO-001

          Before

          The agent incorrectly merged an unseen hybrid-versus-semantic search question into CL-RAG-CHOICE even though the concept, evidence, and answer logic differed from RAG-versus-fine-tuning questions.

          Change

          Required all five clustering tests, prevented existing clusters from being broadened, narrowed question-specific context, and strengthened citation and new-cluster validation.

          After

          The rerun assigned Retrieval, created CL-HYBRID-SEARCH, kept CL-RAG-CHOICE as a near-miss, verified approved sources, and paused at pending human review.

          Known limitations

          • Handles only synthetic questions for the fictional Retrieval-Augmented Generation session; it has not been validated with real learners, mentors, or course data.
          • Supports English-language questions only; multilingual categorization, retrieval, drafting, and evaluation have not been tested.
          • A mentor can manually enter a synthetic demo question, but the prototype does not ingest an actual learning-platform chat stream. Questions are processed sequentially, simultaneous mentor and TA review is unsupported, and manually entered questions disappear when the page is reloaded.
          • Requires approved sources and records in the embedded file formats; it cannot retrieve current vendor information or other unapproved external evidence.
          • Stores API settings and evaluation state only in the current browser; it provides no shared production audit store, cross-session learner memory, reports, emails, or learning-platform integration.
